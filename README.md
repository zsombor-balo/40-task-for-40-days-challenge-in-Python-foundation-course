# 40-task-for-40-days-challenge-in-Python-foundation-course
🏴󠁧󠁢󠁥󠁮󠁧󠁿 The course language was Hungarian, therefore variable names, comments, and notebook notes may also appear in Hungarian. 40 tasks completed during a 40-day Python challenge covering loops, functions, conditionals, lists, dictionaries, and basic problem-solving to strengthen Python fundamentals.

🇭🇺
Ez a repo egy 40 napos Python alapjai tárgy kihívásos feladatait tartalmazza.
A challenge célja a Python alapjainak gyakorlása és megerősítése napi szintű feladatmegoldásokon keresztül.
A notebookok és feladatok olyan alapvető témákat érintenek, mint: változók, ciklusok, feltételek (if-elif-else),  függvények,  listák, és dictionary-k alapvető problémamegoldás. A kurzus nyelve magyar volt, ezért a változónevek, kommentek és egyes notebook jegyzetek magyar nyelven szerepelhetnek.
A repo célja a fejlődés dokumentálása, valamint a Python alapok gyakorlása rendszeres, napi tanulással.
A feldatokat a debreceni egyetem állította össze.
